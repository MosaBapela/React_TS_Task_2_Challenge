# Links Vault — Clean links manager

A simple links vault app built with React + TypeScript and Vite. Save, search, edit and delete links stored locally in your browser.

Quick start
- Install: `npm install`
- Run dev server: `npm run dev`

Project structure (high level)
- `src/Components` — UI pieces (form, list, item, modal, footer)
- `src/Types` — types and local storage helpers

Notes
- The UI uses a subtle left-panel + stacked cards layout (inspired by job-board designs). The form on the left is used to add or edit links.
- Accessibility: form inputs use native labels and focus styles. Tags and actions are keyboard-accessible.
